# PF 2026 Setup

Install everything you need for C++ class in one step.

## Instructions

1. Open PowerShell **as Administrator** (search "PowerShell" in Start, right-click, "Run as administrator").
2. Paste this line and press Enter:

```
Set-ExecutionPolicy Bypass -Scope Process -Force; irm https://raw.githubusercontent.com/nidamunawar/PF-2026-Setup/main/setup.ps1 | iex
```

3. Wait for it to finish. It installs:
   - VS Code (code editor)
   - MinGW (C++ compiler)
   - C/C++ extension for VS Code

4. Close and reopen VS Code when done.
